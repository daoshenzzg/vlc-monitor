# 使用与故障提示

## 区域、规则与保存

拖动已有框可移动，拖动右下角可缩放。框选时 `Esc` 取消；区域规则有草稿时用“应用规则 / 取消编辑”处理。“应用规则”影响当前运行；“保存配置”保留到下次启动，两者不是同一动作。删除区域保留历史记录。

黑屏与疑似静帧按连续有效采样次数触发，恢复也按连续次数确认。无新鲜帧、视频比例改变、区域编辑或调度中断时，不能把画面当成正常继续计数。请在正常内容与故障样本上核对阈值；字幕、时钟、静态节目页会影响静帧判断。

## 本地提醒

“设置 → 常规”里有声音、首次前台提醒及未确认提醒间隔。修改后先应用；取消仅丢弃本地草稿，不撤回已经执行的微信动作。测试入口使用已应用配置，可选择立即或 5 秒后，只测试本地提醒，不发送微信。

告警确认后，异常仍持续时保留弱提示；只有实际正常恢复才标为恢复。底部静音可随时取消，不会开启已在设置里关闭的声音，也不影响微信。

## 播放、VLC 与错误

- 地址变化不自动切源，停止播放后再播放新地址；回车不能绕过停止阶段。
- 正在连接时唯一播放按钮变为“取消连接”；正在停止/取消时不能创建第二播放器。
- “重试停止”表示播放器尚未安全释放，清理完成前不能重新播放。
- 没有有效视频时先检查本机 VLC 是否能直接播放。额外认证交互、插件或自定义选项不一定由本工具的输入框覆盖。
- “设置 → 常规 → 播放器与支持”可修改 VLC 位置、查看诊断、导出脱敏配置。修改 VLC 位置需手动保存并重启，不热替换原生库。
- Mac 选择完整 `.app`，Windows 选择完整 x64 安装目录。取消不会修改已有路径；启动缺失 VLC 的流程可以明确退出。

不要把真实地址、签名参数、二维码、挑战、配置或完整诊断发到公开仓库。诊断可能包含本机路径，分享前应人工检查；脱敏配置移除媒体来源，其他字段也需核对。

## 微信与历史

旧 schema 2 的微信重复提醒开关会被规范化为关闭，旧间隔字段仅为兼容保留，不再影响发送。数据库原表与旧 repeat 历史可继续读取，不会产生新的周期微信消息。本地周期提醒不变。

首次失败、过期或容量拒绝后，已跟踪事件的正常恢复仍有独立发送机会，并提示首次未确认成功。没有首次上下文的孤立恢复不会凭空补发。每阶段最多三次总尝试，原始 TTL 为 300 秒，重复事件不延长预算。队列满、失败、过期和取消应在历史/状态中可见，不能把队列入队或接口接受当成送达。

历史使用专用线程，界面立即显示内存状态。锁冲突、磁盘错误或拥塞时会明确标记部分历史未保存。退出会先停止监播与通知，接纳最终回执，再封闭存储入口并保存；若保存超时/失败，可重试或明确放弃未保存的历史，仍需等待线程安全关闭。配置是否保存与历史是否持久化是不同问题。

## 更新与回退

本次复制到独立项目，未删除父目录源码或旧发布包；新候选不得与旧 App 同时访问运行数据。回退前正常退出当前程序。旧版本可能重新使用旧微信 repeat 配置，回退后需手动核对，不能依赖新版的禁用逻辑。

真实微信基础收发与旧版真实告警已有用户验收，本次未要求重新绑定；新版首次/恢复、断网重试、Windows 和长期值守仍需分别补充目标环境证据。
